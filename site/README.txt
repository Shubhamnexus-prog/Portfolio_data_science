Keep all listed files in the same folder. No build step needed.

Option A: Netlify Drop (easiest, 1 minute)
  1. Unzip this folder.
  2. Go to app.netlify.com/drop and drag the site folder onto the page.
  3. You get a live link. Rename it in Site settings > Change site name.

Option B: GitHub Pages
  1. Create a new GitHub repo, e.g. portfolio, and upload all files in this folder.
  2. Repo Settings > Pages > Branch: main, folder: /site > Save.
  3. Your site appears at https://<your-username>.github.io/portfolio/

Option C: Vercel
  1. Push the folder to GitHub, then import the repo at vercel.com/new.
  2. Framework preset: Other. Deploy.

Before you deploy, edit index.html (any text editor) and:
  - Replace each "Source Code" link (currently https://github.com/Shubhamnexus-prog)
    with the repo of that project.
  - Check dates and wording in Experience.
